Make an icon for this Substance filter in the same style as my other world space filters (see `world_space_non_uniform_blur.sbs`).

**The style:** the icon is the filter's own result on a test sphere. A cube-mapped sphere with 6 UV islands (one mirrored) carries a colourful 3D checker. The filter is applied with a spatially varying setting, so one area of the sphere stays untouched and the effect is easy to compare against it. The sphere is rendered flat (unlit), orthographic, anti-aliased, on a transparent background. Every filter must use the same mesh, pattern, camera and framing so the icons read as one family:
- **Colour graph:** the colour icon, made by running the colour graph on the colour checker.
- **Grayscale graph:** the grayscale icon, made by running the grayscale graph on the checker's luminance.

**Steps**

1. **Build the test inputs** with the code below: a 512×512 position map normalized to [0,1] (like Painter's), a UV mask, the colour checker, and a "control" map that is black on the −X side and white on the +X side (`(x+1)/2`).
2. **Run the actual filter** on those inputs. Choose parameters that show the effect clearly. Feed the control map into whatever parameter or map makes the effect vary in space (blur map, mask, intensity map…), so the −X side stays close to the original.
   - Use the real graph, not an imitation. If the graph is made only of pixel processors, `tools/sbsinterp.py` from `sublimerage/sd_world_space_non_uniform_blur` can run the `.sbs` file directly in numpy.
   - If the graph can't be run, reimplement its exact algorithm in numpy and say so.
   - For the grayscale icon, run the grayscale graph on `luminance(checker)`.
3. **Render** the result with `render()` below (128×128 RGBA, 4× supersampled). Also save a 512 px version.
4. **Embed** each PNG in its graph inside `<attributes>`, after `<description>`, in the `.sbs` icon format (code below). The format is `base64(uint32 big-endian PNG size + zlib(PNG))` with `datalength` = PNG size. If the package is generated by a script, do it in the script.
5. **Check the result:** look at the icon at 256, 128 and 32 px on a dark (#2B2B2E) background. Confirm both the untouched area and the filtered area are recognisable, and show me the preview.

```python
import base64, struct, zlib, io, math
import numpy as np
from PIL import Image
from scipy import ndimage
from scipy.ndimage import map_coordinates

# --- test mesh: cube-mapped unit sphere, 6 islands in 128px tiles of a 512 map, 4px gutter ---
FACES = {  # name: (tile col, row, axis, sign, rot90 count, mirrored)
    '+X': (0, 0, 0, +1, 0, False), '-X': (1, 0, 0, -1, 1, False), '+Y': (2, 0, 1, +1, 2, False),
    '-Y': (0, 1, 1, -1, 3, False), '+Z': (1, 1, 2, +1, 0, True),  '-Z': (2, 1, 2, -1, 1, False)}

def make_sphere(res=512, tile=128, gutter=4):
    pos = np.zeros((res, res, 3), np.float32); mask = np.zeros((res, res), np.float32)
    for name, (cx, cy, ax, sg, rot, mir) in FACES.items():
        s = tile * res // 512; g = gutter * res // 512; x0, y0 = cx * s + g, cy * s + g; n = s - 2 * g
        a = (np.arange(n) + 0.5) / n * 2 - 1; A, B = np.meshgrid(a, a)
        for _ in range(rot): A, B = -B, A
        if mir: A = -A
        p = np.zeros((n, n, 3)); o = [i for i in range(3) if i != ax]
        p[..., ax] = sg; p[..., o[0]] = A; p[..., o[1]] = B
        p /= np.linalg.norm(p, axis=-1, keepdims=True)
        pos[y0:y0 + n, x0:x0 + n] = p; mask[y0:y0 + n, x0:x0 + n] = 1
    idx = ndimage.distance_transform_edt(mask == 0, return_distances=False, return_indices=True)
    return pos[idx[0], idx[1]], mask          # world positions (dilated into the gutter), UV mask

def checker(pos):                             # colourful 3D checker, continuous across seams
    f = np.floor(pos * 3.0 + 100.37).astype(int)
    chk = ((f[..., 0] + f[..., 1] + f[..., 2]) % 2).astype(np.float32)
    return np.stack([chk, 0.5 * chk + 0.5 * (pos[..., 1] > 0), 1 - chk], -1)

def control(pos):                             # black at -X (untouched) -> white at +X (full effect)
    return np.clip((pos[..., 0] + 1) / 2, 0, 1).astype(np.float32)

pos, mask = make_sphere()
P = pos[mask > 0.5]; mn, mx = P.min(0), P.max(0)
position_map = (pos - mn) / (mx - mn).max()   # feed this (RGB, alpha 1) as the Mesh Position input
luminance = lambda c: c @ np.array([0.2126, 0.7152, 0.0722])

# --- render: same camera for every filter ---
VIEW, SPHERE = (-0.6, -0.4, -0.7), 0.94       # view direction (towards camera), diameter / icon size

def sphere_uv(p, res=512):                    # unit-sphere points -> texel (row, col), inverse of make_sphere
    ax = np.argmax(np.abs(p), -1); rows = np.zeros(len(p)); cols = np.zeros(len(p))
    tile = 128 * res // 512; g = 4 * res // 512; n = tile - 2 * g
    for name, (cx, cy, a, sg, rot, mir) in FACES.items():
        sel = (ax == a) & (np.sign(p[:, a]) == sg)
        if not sel.any(): continue
        q = p[sel] / np.abs(p[sel, a:a + 1]); o = [i for i in range(3) if i != a]
        A, B = q[:, o[0]].copy(), q[:, o[1]].copy()
        if mir: A = -A
        for _ in range(rot): A, B = B, -A
        cols[sel] = cx * tile + g + np.clip((A + 1) / 2 * n - 0.5, 0, n - 1)
        rows[sel] = cy * tile + g + np.clip((B + 1) / 2 * n - 0.5, 0, n - 1)
    return rows, cols

def render(tex, res=128, ss=4):               # tex: filter output, (512,512,3) in [0,1]
    R = res * ss; v = np.array(VIEW, float); v /= np.linalg.norm(v)
    r = np.cross([0, 1.0, 0], v); r /= np.linalg.norm(r); u = np.cross(v, r)
    c = ((np.arange(R) + 0.5) / R * 2 - 1) / SPHERE; X, Y = np.meshgrid(c, -c)
    rr = X * X + Y * Y; inside = rr < 1; z = np.sqrt(np.clip(1 - rr, 0, 1))
    pts = X[inside, None] * r + Y[inside, None] * u + z[inside, None] * v
    rows, cols = sphere_uv(pts, tex.shape[0]); rgb = np.zeros((R, R, 3))
    for k in range(3):
        rgb[inside, k] = map_coordinates(tex[..., k], [rows, cols], order=1, mode='nearest')
    a = inside.astype(float)
    rgb = (rgb * a[..., None]).reshape(res, ss, res, ss, 3).mean((1, 3))
    a = a.reshape(res, ss, res, ss).mean((1, 3))
    out = np.concatenate([rgb / np.maximum(a[..., None], 1e-6), a[..., None]], -1)
    return Image.fromarray((np.clip(out, 0, 1) * 255 + 0.5).astype(np.uint8), 'RGBA')

# --- .sbs icon element (goes inside <attributes>, after <description>) ---
def icon_xml(png_path):
    png = open(png_path, 'rb').read()
    data = base64.b64encode(struct.pack('>I', len(png)) + zlib.compress(png, 9)).decode()
    return '<icon><datalength v="%d"/><format v="png"/><strdata v="%s"/></icon>' % (len(png), data)
```

**What to avoid:**
- Don't change the mesh, pattern, colours, view or framing.
- Don't add lighting, an outline or a background.
- Don't fake the effect with generic image filters when the real graph can be run.
- If one icon has to serve a filter with a single graph, use the colour version.
